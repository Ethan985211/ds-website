CAPABILITIES

一个管家,六项能力

围绕日常桌面工作设计,每项能力都跑在本地,可以按需组合。

01

本地对话

接入本地大模型(Ollama),自然语言对话与任务执行不经过任何云端服务。

02

文件检索

混合检索(BM25 + 向量 + RRF)在本地索引中快速定位文档,支持 PDF / Word / Excel 等格式。

03

长期记忆

四层记忆体系自动提取、巩固与遗忘,跨会话记住你的偏好与上下文,越用越懂你。

04

插件与技能

可插拔插件库与技能扩展,按需开启工具能力,能力边界透明可控。

05

联网能力

需要时按需联网获取信息,开关在手,默认离线,不主动上传任何数据。

06

安全授权

写操作需要授权确认,权限门控透明可追溯,敏感动作先问后做。

TECHNOLOGY

为本地而生,可解释可验证

不为堆砌工程规模,只为可解释、可答辩、可验证的本地智能体。

T/01

轻量 ReAct 循环

自研轻量 ReAct 智能体循环,推理、调用、观察,每一步可追溯。

T/02

混合检索

BM25 + 向量 + RRF 融合排序,召回准、开销低,本地索引毫秒级响应。

T/03

四层记忆

语义 / 情境 / 程序记忆自动提取与维护,向量检索注入,巩固与遗忘。

T/04

安全授权门

写操作授权确认 + 审计留痕,权限模型清晰,不越权、可反查。

系统要求

  • Windows 10+ 64 位

本地模型
