Get Started

开始使用

安装即可使用，无需注册账号，数据保存在本机

Windows 应用包

NSIS 向导安装。模型在首次启动时下载到本机。

  • 安装包 ~115 MB
  • 首启下载模型（约 3.4 GB）
  • 需 Ollama，或已有 model-pack
  • 免注册，本地运行
Windows 10/11 x64 ~115 MB Setup.exe ~3.4 GB 首启模型 本地优先
DS-Desktop-0.3.0-beta.1-setup.exe

默认模型 Qwen3:4b + bge-m3

系统要求

  • Windows 10/11 x64
  • 建议 16 GB 内存（8 GB 可试）
  • 预留磁盘：模型约 3.4 GB+

本地模型

  • 默认 Qwen3:4b + bge-m3，首启引导安装
  • 也可导入本地 model-pack
  • 模型保存在本机，推理默认不上传

隐私

  • 数据保存在本机，默认离线
  • 无需账号与注册
  • 联网开关由你控制，按需开启
