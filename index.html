Get Started

开始使用

Windows 应用包

轻量安装包；首次启动引导把模型下到本机目录，数据不离机。

  • 体积小（程序 + 界面）
  • 首次启动引导下载模型到本机目录
  • 需网络下载模型，或已有 model-pack / Ollama
  • 无需注册账号，安装后即可启动
Windows 10/11 x64 ~166 MB 应用包 ~3.4 GB 首启模型 本地优先
DS-Desktop-0.3.0-beta.1-windows-x64-app.zip

安装后首次启动按引导下载模型（默认 Qwen3 + bge-m3，约 3.4 GB）

系统要求

  • Windows 10/11 64 位（以验收为准）
  • 建议 16 GB 内存（8 GB 可试，4 GB 不承诺）
  • 应用包很小；模型约 3.4 GB + 运行占用

本地模型

  • 默认模型 Qwen3:4b + bge-m3，首启引导安装
  • 也可导入本地 model-pack，无需再下
  • 模型保存在本机目录，推理默认不上传

隐私

  • 数据保存在本机，默认离线
  • 无需账号与注册
  • 联网开关由你控制，按需开启
